# طلسم جفر جنریٹر — Talism Jafar Generator

Free prototype web tool recreating the classic Talism Jafar concept:
enter Talib and Matloob names (with mothers' names), select the purpose,
and get Abjad totals, the base line (Satr-e-Asasi), demo Takseer rows and a 3x3 Loh grid.

**Live (GitHub Pages):** https://farrakhimtiaz74.github.io/talism-jafar-generator/
**Repo:** https://github.com/farrakhimtiaz74/talism-jafar-generator

## Status: Prototype
The Abjad counting works, but the Takseer is a demo algorithm.
The verified classic Jafar formula will be added in a later version after checking it against an authentic source.
This tool is for traditional / rohani guidance only — no result is guaranteed.

## Features
- Urdu RTL, mobile-first, dark green + gold theme
- 100% in-browser — names are never uploaded anywhere
- Purposes: Taskheer/Mahabbat, Adawat/Bughz, Rohani Ilaj/Kamyabi
- Extensions: Kabeer / Wast / Sagheer, Takseer lines up to 100
- Copy result, download TXT, WhatsApp share

## Tech
Single `index.html` — no build, no server, no Netlify. Hosted on GitHub Pages from this repo.
